Zipper does the work
seq(a, b) runs in order. emit(value) prints a value. define(name, x, q{…}) saves a body; x() evaluates its delayed argument each time it is used.
Zipper resolves its own definitions first. An unresolved function name passes through to the live page's JavaScript. Nested arguments run left to right, one rewrite at a time. Numbers, strings, booleans, null and undefined are values.

    
Use browser functions directly
emit(Math.round(3.7))
Reflect.set(document.querySelector("#heading"),
  "textContent", "Hello from Zipper")
call(document.querySelector("#items"),
  "insertAdjacentHTML", "beforeend", "<li>Hello</li>")
Reflect.get(object, "property") reads a property; Reflect.set(object, "property", value) changes it. The live page supplies call(object, "method", args…) to invoke a method on a returned object with the correct receiver.

    
Follow every value
Calls such as fetch(url) are awaited automatically. Use call(fetch(url), "json") to read a JSON response. Browser objects appear as ref{1} on the tape and keep their identity between calls. Internal value(q{…}) tapes evaluate a Zipper function used as an argument and return its last value.
Only emit prints to Output. Browser calls change the live page and can write to Browser console. Back restores up to 100 language steps but stops at browser effects. Reset clears references and creates a fresh page. Async calls time out after 10 seconds.
The live page is a sandbox with its own document. Fetch follows browser CORS rules with an opaque origin; external servers must allow that origin or *. Programs run only when you press Run or Step. Save .piz keeps a copy of your source.
