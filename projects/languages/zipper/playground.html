Three small building blocks
seq(a, b) runs expressions in order. emit("text") prints a string. define(name, x, q{…}) saves a body; calling x() inside it runs the argument.
Strings use double quotes, with \n, \t, \" and \\ escapes. Use q{…} to delay code. The internal def(…) and env{…} records show captured definitions.

    
Reach into the page
js("document.querySelector('#heading').textContent = 'Hello!'")
js("return Math.round(Math.PI * 100)")
js("console.log(navigator.language)")
JavaScript is an async function body: use await for browser calls and return to print a result. State persists on window until Reset. Each complete JavaScript call is one Zipper step.

    
Make it yours
The live page is a separate browser sandbox. DOM, canvas and browser APIs are available there; it cannot change the surrounding editor. Fetch uses normal browser CORS rules with an opaque origin, so a server must allow that origin (or *). Storage and permission-based APIs may be restricted.
Programs run only when you press Run or Step. Nothing is saved automatically. Save .piz downloads your code. Back keeps up to 100 recent language states and stops at browser calls. Async browser calls time out after 10 seconds and reset the live page; synchronous JavaScript must yield to keep the tab responsive.
